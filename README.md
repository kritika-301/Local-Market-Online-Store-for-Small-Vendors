Stallside – Local Market Online Store for Small Vendors

About the Project

Stallside is a local market online store designed to help small vendors display and sell their products online. It provides customers with a simple platform to explore local products, browse vendors, add items to their cart, and place orders.

Problem Statement

Small local vendors often lack an affordable and accessible online platform to showcase their products and reach more customers. Stallside aims to provide a simple digital solution to improve their online visibility and make local shopping more convenient.

Features

Browse products from local vendors.

Search and filter products by category.

Sort available products.

View vendor information.

Add products to the shopping cart.

Increase, decrease, and remove cart items.

Place orders with pickup or delivery options.

Select cash or UPI as a preferred payment method.

Register as a vendor and add products.

Manage orders through the vendor desk.

Submit customer feedback.

Switch between light and dark themes.

Technologies Used

HTML: Structures the website.

CSS: Handles styling, layout, and responsiveness.

JavaScript: Implements interactive features and functionality.

Local Storage: Stores project data in the user's browser.

How to Run

Download or clone this repository.

Open the index.html file in a web browser.

Explore the website and its features.

Limitations

The current version uses browser Local Storage instead of a shared database. It does not include a real payment gateway, secure vendor authentication, or live delivery tracking.

Future Scope

Add a backend and shared database.

Implement secure user and vendor accounts.

Integrate a real payment gateway.

Add delivery tracking.

Improve accessibility and mobile functionality.
